AgentGate

One verified person.
One pass. No Sybil farms.

AgentGate is a reusable smart-contract gate for BNB Smart Chain. Any project can inherit it to restrict a drop, a mint, or any function to holders of a SPACE ID Agent ID — a non-transferable identity that one verified person can hold exactly once. If you hold an Agent ID, you pass. Bots with a thousand fresh wallets don't.

Check your eligibility

Reads the Agent ID contract on BSC directly from your browser — no wallet signature, no data leaves your device except a public RPC call.

Demo: the AgentGate Badge

A free commemorative ERC-721 badge (AGB) proving your Agent ID passed the gate. One per holder, ever. It promises nothing of value — it is a proof of identity, not an investment.

For projects: integrate in three lines

Inherit AgentGate, point it at the Agent ID contract, and guard any function with _requireAgentID(). That is the whole integration.

import {AgentGate} from "./AgentGate.sol";

contract MyDrop is AgentGate {
    // BSC mainnet Agent ID (SPACE ID): 0x60b9262456de011f7d15a54cdd8c48baaa8b022f
    constructor() AgentGate(0x60b9262456de011f7d15a54cdd8c48baaa8b022f) {}

    function mint() external {
        _requireAgentID();   // reverts unless the caller holds an Agent ID
        // ... your drop logic; one-person-one-pass is now enforced
        //     by the identity itself, not by an allowlist you maintain.
    }
}

Full source, tests and the reference badge contract are open source (MIT) — see the project repository. The Agent ID address is immutable in the gate: it can never be swapped for a weaker identity contract after deployment.

Owner powers — the complete list

The AgentGate Badge contract is intentionally almost powerless. Its owner can only:

  • Open or close the mint window (setMintOpen).
  • Lower the supply cap (setMaxSupply) — never raise it, never below the amount already minted.
  • Transfer or renounce ownership — renouncing freezes the two powers above forever.

The owner cannot mint (they must pass the same Agent ID gate as everyone else), cannot block or reverse transfers, cannot charge fees, and cannot withdraw funds — the contract has no payable functions and holds no funds. The badge is free and always will be.
